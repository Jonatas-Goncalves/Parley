What you can do

Structured speaking, listening, reading, and vocabulary exercises designed to work offline from start to finish.

Voice Practice

Role-play one of 19 everyday situations with a tutor that replies in your target language. Switch between continuous listening or push-to-talk, speak or type, and read a concise note about your mistakes after each turn.

Pronunciation

Read a generated phrase out loud and inspect word-by-word recognition accuracy in real time. Words recognised cleanly turn green, while missed or mispronounced words turn red.

Spoken Stories

Listen to 49 short public-domain stories read aloud for natural listening immersion. Installers stay lean—the audio pack is downloaded only when you explicitly request it in Settings.

Complete the Sentence

Listen to a short generated passage and fill in the missing words. The built-in player includes seek and playback speed controls, and clicking Finish grades every blank in green or red.

Conversation Progress

Every session earns a personal 0–100 score measured from speaking pace, pauses, vocabulary variety, answer length, and recogniser confidence—plus a guided level test inspired by IELTS and TOEFL speaking tasks.

Zero Cloud, Zero Telemetry

Speech recognition (faster-whisper), LLM generation, and TTS (Piper) run locally. Your audio, transcripts, and per-language history never leave your computer.

First Run & Local Model Tiers

Onboarding detects your hardware, configures your preferred LLM backend, and preloads the model automatically from the second launch onward.

Ollama

Easiest Option

Install from ollama.com. Parley detects an already-running instance (reusing it without spawning duplicates), or starts Ollama and pulls your selected model automatically.

llama.cpp

Lighter & Self-Contained

No external daemon required. Parley downloads the GGUF model file once and manages llama-server itself, opening the session as soon as the model is loaded.

Recommended Quality Tiers

Smaller models respond faster; larger models make fewer grammar mistakes

Build & Run from Source

Requires Python 3.11+, GTK 4, PyGObject, PortAudio, libsndfile, and FFmpeg.

openSUSE (zypper) 
sudo zypper install python313 python313-gobject \
  python313-gobject-Gdk gtk4 typelib-1_0-Gtk-4_0 \
  libportaudio2 libsndfile1 ffmpeg google-noto-sans-cjk-fonts
Debian / Ubuntu (apt) 
sudo apt install python3 python3-venv python3-gi \
  gir1.2-gtk-4.0 libportaudio2 libsndfile1 \
  ffmpeg fonts-noto-cjk
Virtual Environment, Run & Tests 
python3 -m venv --system-site-packages .venv
. .venv/bin/activate
pip install -e ".[dev]"
python -m parley

# Lint & test suite
ruff check src scripts tests packaging
pytest

Tip: On headless machines use GDK_BACKEND=x11 with an X server. For Fedora/Arch CJK fonts, install google-noto-sans-cjk-fonts or noto-fonts-cjk. Packaging guides live in docs/build.md.
